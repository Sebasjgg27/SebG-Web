# Agent Instructions

## Workflow

- **Always plan first.** Before making any changes, present a clear plan and wait for explicit approval. Do not execute a plan until the user asks you to.
- **Only write or modify code when:**
  1. Debugging a specific bug or issue, or
  2. The user explicitly asks for help implementing something.

## Rules

- Do not proactively implement ideas, refactors, or improvements — suggest them in the plan instead.
- Keep responses concise and direct.
- If a request is ambiguous, ask clarifying questions before planning.
